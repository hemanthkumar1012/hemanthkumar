# Hemanth Kumar — Stark Systems Portfolio

Tony Stark / Iron Man-inspired personal portfolio for **Hemanth Kumar**, featuring an original animated arc-reactor-inspired illustration and a cinematic dark-metal, titanium, red, gold, and cyan interface.

## Live site

https://hemanthkumar1012.github.io/hemanthkumar/

## Highlights

- Original inline SVG arc-reactor-inspired hero illustration with animated rings and core glow.
- Responsive interface with scroll progress, reveal transitions, project filters, mobile navigation, and a lightweight canvas particle network.
- Projects, repository archive, skills, experience, education, certifications, and social/contact links.
- Respects reduced-motion preferences.

## Deploy

The `.github/workflows/pages.yml` workflow deploys the repository root to GitHub Pages on pushes to `main`. In repository settings, use **Pages → Build and deployment → Source → GitHub Actions**.

This portfolio uses original CSS/SVG composition; it does not bundle movie footage or copyrighted character artwork.
